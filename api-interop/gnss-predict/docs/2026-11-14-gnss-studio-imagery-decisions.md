## การตัดสินใจ (Ruling — เหตุผล — ถ้าผิดเสียอะไร)

1. ผู้ใช้เลือก "ทาง ข" แล้วลงมือทันทีโดยไม่รอตรวจ spec — ผู้ใช้ชอบให้ทำแล้วรายงาน — แก้ตามที่ผู้ใช้เปลี่ยน
2. ดาวกล้องเป็น object (Himawari, GOES, Terra ฯลฯ) แยกไปงาน ข2 — ต้องแก้ engine ให้รองรับดาวที่ไม่ใช่ GNSS — ผู้ใช้ยังดูภาพจากตำแหน่งดาวกล้องไม่ได้ในรอบนี้
3. ไม่อ่าน GetCapabilities ระหว่างใช้งาน ใช้ผล 4xx ต่อชิ้นแทน — ลดการต่อเน็ตและการ parse XML ที่ไม่น่าเชื่อถือ — บอกช่วงเวลาที่มีภาพล่วงหน้าไม่ได้
4. ตัวเปิดการเชื่อมต่อของ server ปฏิเสธ redirect ทุกกรณี — กันการถูกพาไปโฮสต์อื่น — ไม่มี
5. คำขอที่เจอ 403/429 จาก GIBS ตอบ 502 และคำขอถัดไปตอบ 503 `IMAGERY_PAUSED`; 403/429 ไม่นับในตัวนับ 20 ครั้ง — การพัก 15 นาทีครอบคลุมแล้ว — รหัสสถานะต่างไป 1 ตัว
6. ชั้นคงที่ (Blue Marble) ใช้ Time = `default` ตามแม่แบบ URL — รอยืนยันกับ GIBS จริง (B0) — ชั้นนี้อาจโหลดไม่ขึ้นจนกว่าจะแก้ `upstream_url`
7. เปลี่ยนเวลาภาพแล้วคงชั้นเก่าไว้ใต้ชั้นใหม่จนชั้นใหม่โหลดชิ้นแรก (ไม่เกิน 2 ชั้นต่อ id) — ไม่ให้ภาพกะพริบดำ — อาจเห็น Natural Earth เป็นหย่อมสั้น ๆ
8. หน้าเว็บได้ 403 จากชิ้นภาพ = ปิดชั้น GIBS ในเครื่อง (ไม่ PUT); 404 = ไม่มีภาพ; อย่างอื่นไม่นับ ไม่ลองซ้ำ — server ตอบ 403 เฉพาะสวิตช์ปิด — สัดส่วนบน HUD คลาดเล็กน้อย
9. สัดส่วน "ไม่มีภาพ" บน HUD หารด้วยชิ้นที่ได้ผลแล้ว ไม่ใช่ชิ้นที่ขอ — ไม่นับชิ้นที่กำลังโหลด — ข้อความขึ้นเร็วขึ้นเล็กน้อย
10. เมนู "Globe Manager" ไม่มี "..." — เป็นคำ STK ตรงตัว (STK ref §H) — แค่หน้าตา
11. ยกข้อเล็กขึ้นมาแก้ในรอบตรวจรวม: ชั้น GIBS มืดตาม Ambient Level, HUD บอกเวลาของภาพที่เห็นจริง, เครดิต NASA/JMA/NOAA บนจอ,
    ข้อความยืนยันบอกว่า IP และ User-Agent ถึง NASA ด้วย — ผู้ใช้เห็นได้และเป็นเรื่องความตรงไปตรงมา — diff เพิ่มเล็กน้อย
12. ไม่แก้: ติ๊กสวิตช์ใน Globe Manager อาจเขียนทับ `settings.json` ที่แก้มือจนผิดรูป (ได้ค่าปลอดภัย daily ปิด); สวิตช์ที่เปลี่ยนจากอีกแท็บไม่เห็นจนโหลดใหม่ — ทิศทางปลอดภัย — ค่าที่แก้มือหาย
13. ลูกล้อแบบบรรทัด/หน้า นับอย่างน้อย 100 px ต่อครั้ง — ให้ล้อ Firefox หนึ่งจังหวะซูมได้ — ไม่มี
14. ชิ้นภาพที่ยังไม่นิ่ง (รายวันของวันนี้/เมื่อวาน, 10 นาทีของ 3 ชั่วโมงล่าสุด, อนาคต) ไม่เก็บลงดิสก์ — GIBS ยังเติมภาพไม่ครบ ภาพเก่าจะค้าง — ดึงซ้ำบ่อยขึ้นสำหรับช่วงล่าสุด
